|---------|-----------|------------------|-------------------|-------------------|

## Тело ответа

Кроме того, в ответе будет содержаться информация об ошибке - ее уникальный идентификатор, имя, описание, а так же дополнительная информация при необходимости. Все описание передается в формате JSON.

| Value | Description |
|-------|-------------|
| **ErrorID** <br> *integer* | Поле содержит уникальный идентификатор ошибки |
| **ErrorName** <br> *string* | Поле содержит краткое название ошибки |
| **ErrorDescription** <br> *string* | Поле содержит описание ошибки |


```bash
HTTP/1.1 404 Not Found
```

```JSON
{
    "ErrorDescription": "No handler for path",
    "ErrorID": 5001,
    "ErrorName": "NoPathHandler"

```

### Пример 3

Тело содержит дополнительную информацию об ошибке.

```JSON
{
    "ErrorDescription": "Error while parsing XML",    // описание ошибки
    "ErrorID": 5004,     // ID ошибки
    "ErrorName": "ParseXmlError",      // имя ошибки
    "errorParseXMLColumnNumber": 20,       // (доп. информация) номер столбца в xml документа, в котором встретился неверный символ
    "errorParseXMLDescription": "Не удалось прочесть XML структуру", // (доп. информация) уточнение ошибки
    "errorParseXMLLineNumber": 1    // номер строки в xml документе, в котором встретился неверный символ
}
```
