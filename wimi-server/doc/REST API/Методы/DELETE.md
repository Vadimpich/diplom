# DELETE

## Models

### Описание

| Property | Value |
|----------|-------|
| **Назначение** | Запрос на удаление модели. |
| **Метод** | DELETE |
| **URL** | `/Models` |

### Структура URL

```bash
http://127.0.0.1:8081/Models?modelID=[id]
```

Где:

- id - id модели

### Пример запроса

```bash
curl curl http://127.0.0.1:8081/Models?modelID={fd30752a-a3cd-4f8f-bec7-fe5dd2157ae9} -X DELETE
```

### Пример ответа

```JSON
{
    "result" : "ok"
}
```

### Примечание

Если в текущий момент модель используется для вычисления, то сервер удалит модель из списка доступных и будет ожидать возврата всех моделей в пул, как только это произойдет – модель будет полностью удалена с сервера. Ответ об успешном завершении операции может быть выслан еще до того, как в действительности произойдет удаление модели.
