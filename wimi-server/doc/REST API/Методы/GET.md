# GET

## Models

### Описание

| Property | Value |
|----------|-------|
| **Назначение** | Запрос на получение информации  по модели. |
| **Метод** | GET |
| **URL** | `/Models` |

### Получение списка доступных моделей

#### Пример запроса

```bash
curl http://127.0.0.1:8081/Models
```

#### Пример ответа

```JSON
[
   "12345",
   "1234"
]           // список id доступных моделей
```

### Получение информации по модели

#### Структура URL

```bash
http://127.0.0.1:8081/Models?modelID=[id]
```

Где:

- id - id модели

#### Пример запроса

```bash
curl http://127.0.0.1:8081/Models?modelID={fd30752a-a3cd-4f8f-bec7-fe5dd2157ae9}
```
#### Пример ответа

```JSON
{
    "constraintsCount": 0,         // кол-во ограничений в модели
    "parametersCount": 69,       // кол-во параметров в модели
    "poolSize": 5,          // размер пула моделей
    "relationsCount": 53,                      // кол-во отношений в модели
    "rulesCount": 218               // кол-во правил в модели
}
```
