Ответ об успешном завершении операции может быть выслан еще до того, как в действительности произойдет удаление модели.

POST запрос для вычисления модели "/ModelsCalc"

В теле запроса передаются:

modelID - id модели, это любой набор символов

incommingParameters – массив известных параметров, состоит из ID параметра и его значения;

outputParameters – массив исковых, состоит только из ID параметров.

 

Опциональные параметры запроса записываются в тэг service:

outputfFields – массив, содержащий ключи формата вывода результата работы API. Допустимые значения:

Значение

Описание

algorithm

Выводит все содержание тега algorithm

requiredExploredParameters

Выводит искомые найденные параметры

requiredUnexploredParameters

Выводит искомые ненайденные параметры

exploredParameters

Выводит все найденные параметры

timing

Выводит время потраченное на разбор запроса, его обработку и формирование ответа в миллисекундах

ВНИМАНИЕ: если данный тэг не указан, то выводятся все поля.

 

Пример:

JSON:

{

            "modelID" : "1003",

            "incommingParameters":[

                        {

"value":5,

"id":"P2014-07-22124737011-00835"

},

                        {

"value":2,

"id":"P2014-07-22124822824-00590"

}

            ],

            "outputParameters":[

"P2014-10-17141000865-08165",

                        "P2014-10-21124302106-09847"],

            "service":{

                        "outputFields":["requiredExploredParameters","timing"]

            }

}

            packages – массив, содержащий все пакеты запросов на вычисление модели.

Каждый пакет содержит в себе все обязательные поля, перечисленные для API /ModelsCalc.

Каждый пакет может содержать в себе необязательные поля API /ModelsCals.
