# Разворачивание WiMi на Windows

## Запуск

Из папки, куда был распакован WiMi Server, запустить программу `WiMi` с ключом `-e`:

```powershell
WiMi.exe -e
```

## Автозапуск

Для того, чтобы Wi!Mi запускался автоматически, требуется создать папку автозапуска. Подробнее в [статье](https://zen.yandex.ru/media/tehnichka/kak-legko-nastroit-avtozagruzku-programm-windows-10-5e96cf382d34573bbda1e64a).

Для этого нужно выполнить команду `shell:startup`.

Далее копируем созданные ярлык запуска WiMi с нужным ключем в созданную папку.
