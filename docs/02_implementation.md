- Phase 2 закрыт reproducibility-обвязкой: локальный compose stack теперь поднимает frontend, core backend, PostgreSQL, RabbitMQ, MinIO и `text/acoustic/paralinguistic` stub workers как один проверяемый runtime; core backend использует явный `RABBITMQ_URL`, worker-очереди объявляются с теми же quorum/DLX retry аргументами, а runbook/validation зафиксировали команды smoke-проверки и operator-facing `processing-status` progress polling для shipped transactional outbox и channel queues pipeline.
