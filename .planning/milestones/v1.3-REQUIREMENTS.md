## v1 Requirements

### Admin Shell Discipline

- [x] **ADUI-01**: Административный контур остаётся отдельным от operator UI, но теряет dashboard-паттерны, описательные блоки и любые экраны, которые не сводятся к `header + actions + table/form`
- [x] **ADUI-02**: Боковая навигация администратора остаётся структурно прежней, занимает всю высоту viewport, не растягивается контентом и держит кнопку выхода у нижнего края
- [x] **ADUI-03**: `/admin` перестаёт быть dashboard-экраном и становится либо прямым redirect, либо тихой навигационной точкой без summary-карточек, объяснений и аналитических блоков

### Admin Registries

- [x] **ADUI-04**: Экран пользователей работает как компактный реестр с inline-фильтрами и колонками `login`, `role`, `status`, `last_login`, без декоративных карточек и отдельных кнопок `Открыть`
- [x] **ADUI-05**: Экран опросников работает как компактный реестр с колонками `name`, `questions_count`, `status`, `updated_at`, без usage-metrics, summary-блоков и вторичных визуальных контейнеров
- [x] **ADUI-06**: Экран аудита сведён к плоскому журналу событий в виде таблицы с фильтрами и раскрытием строки, без карточек и dashboard-обвязки
- [x] **ADUI-07**: Экран мониторинга либо удалён из главного акцента, либо сведён к краткому списку статусов сервисов без developer-facing observability UI и без крупных карточек

### Admin Edit Surfaces

- [x] **ADUI-08**: Карточка пользователя сведена к строгой прикладной форме без внутренних технических ремарок, лишних summary-блоков и визуального шума
- [x] **ADUI-09**: Редактор опросника становится single-column surface: только поля формы, список вопросов и управление порядком через drag-and-drop, без правой панели, summary и технических пояснений
- [x] **ADUI-10**: Экран настроек сводится к простой вертикальной форме без описательных текстов, боковых панелей и developer-facing терминологии

### Global Interaction Rules

- [x] **ADUI-11**: Во всём admin UI строки реестров открываются по клику, а не через отдельные action-кнопки `Открыть`
- [x] **ADUI-12**: Во всём admin UI удалены descriptive texts, duplicated metadata, color-heavy cards и любые блоки, не помогающие фильтровать, открыть, изменить или сохранить данные
