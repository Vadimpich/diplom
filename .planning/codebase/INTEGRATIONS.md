# External Integrations

**Analysis Date:** 2026-03-20

## APIs & External Services

**Internal HTTP API:**
- Core Backend HTTP API - consumed by the Next.js frontend
  - SDK/Client: browser `fetch` wrapper in `frontend/lib/api/client.ts`
  - Auth: Bearer JWT stored in cookies by `frontend/lib/auth.ts`

**Object Storage:**
- S3-compatible storage via MinIO - stores uploaded answer audio and creates the bucket on startup
  - SDK/Client: `github.com/minio/minio-go/v7` in `core-backend/internal/storage/s3.go`
  - Auth: `MINIO_ACCESS_KEY_ID` or `MINIO_ROOT_USER`, plus `MINIO_SECRET_ACCESS_KEY` or `MINIO_ROOT_PASSWORD`

**Message Broker (prepared, not active in current code paths):**
- RabbitMQ - provisioned in `docker-compose.yml` and exposed to `core-backend` through env vars, but no publisher/consumer code is detected in `core-backend/`
  - SDK/Client: Not detected in current repository code
  - Auth: `RABBITMQ_USER`, `RABBITMQ_PASSWORD`, `RABBITMQ_VHOST`

## Data Storage

**Databases:**
- PostgreSQL 16 - primary structured data store for users, specialists, examinations, questionnaires, and answers
  - Connection: `DATABASE_URL`
  - Client: `pgx/v5` pool in `core-backend/internal/postgres/client.go` with SQL access generated by `core-backend/db/sqlc/*`

**File Storage:**
- MinIO bucket defined by `MINIO_BUCKET` and accessed through `core-backend/internal/storage/s3.go`

**Caching:**
- None detected

## Authentication & Identity

**Auth Provider:**
- Custom JWT auth
  - Implementation: password verification with bcrypt in `core-backend/internal/auth/service.go`, token issue/parse in `core-backend/internal/auth/jwt.go`, frontend cookie persistence in `frontend/lib/auth.ts`

## Environment Configuration

**Required env vars:**
- Backend required by `core-backend/internal/config/config.go`: `DATABASE_URL`, `JWT_ACCESS_SECRET`, `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY_ID` or `MINIO_ROOT_USER`, `MINIO_SECRET_ACCESS_KEY` or `MINIO_ROOT_PASSWORD`, `MINIO_BUCKET`

- Compose-level infrastructure variables documented in `.env.example`: `POSTGRES_*`, `RABBITMQ_*`, `MINIO_*`, `JWT_*`, `INITIAL_USER_*`, `FRONTEND_HOST_PORT`

**Secrets location:**
- Example values live in `.env.example`
- Actual runtime secrets are expected in a local `.env` loaded by Docker Compose or direct process env; secret files are not committed
