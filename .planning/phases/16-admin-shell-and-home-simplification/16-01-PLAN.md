# Plan 16-01: Simplify admin shell chrome and remove the admin dashboard layer

## Goal

Turn the admin contour entry into a quiet internal-tool surface by stripping shell noise and replacing the current `/admin` dashboard with a minimal navigation-first entry.

## Scope

- `frontend/components/layout/app-shell.tsx`
- `frontend/components/layout/admin-shell.tsx`
- `frontend/app/(app)/admin/page.tsx`
- `frontend/app/(app)/admin/loading.tsx`
- `frontend/components/admin/admin-summary-strip.tsx` if removal is the cleanest path

## Steps

1. Simplify admin shell navigation to label-only items and fixed-height behavior with pinned logout.
2. Remove admin dashboard summary UI from `/admin` and replace it with a minimal redirect or navigation list.
3. Align loading state with the new quiet entry model.
4. Run frontend verification and sync planning/docs.

## Verification

- `cd frontend && npm run lint`
- `cd frontend && npm run build`
- `cd frontend && npx tsc --noEmit`
