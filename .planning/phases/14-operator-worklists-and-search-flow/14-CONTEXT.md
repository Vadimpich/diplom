# Phase 14: Operator Worklists And Search Flow - Context

**Gathered:** 2026-03-25
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 14 removes dashboard behavior from operator home, specialists, and history. Each screen must collapse into one toolbar plus one main worklist, with inline status counts instead of cards and with compact, row-based navigation toward the next action.

</domain>

<decisions>
## Implementation Decisions

- Replace KPI strips and side panels with one inline stats row on the operator home.
- Use dense tables or flat row registries for specialists and examination history.
- Keep existing APIs and reuse current list components after simplifying them.

</decisions>
