# Plan 19-01: Simplify admin edit surfaces into single-column forms and ordered lists

## Goal

Make user, questionnaire, and settings editors feel like direct admin forms instead of documentation-heavy screens with side panels and secondary summaries.

## Scope

- `frontend/app/(app)/admin/users/new/page.tsx`
- `frontend/app/(app)/admin/users/[id]/page.tsx`
- `frontend/components/admin/user-form.tsx`
- `frontend/app/(app)/admin/questionnaires/new/page.tsx`
- `frontend/app/(app)/admin/questionnaires/[id]/page.tsx`
- `frontend/components/admin/questionnaire-builder.tsx`
- `frontend/app/(app)/admin/settings/page.tsx`

## Steps

1. Remove side panels and long page descriptions from user/questionnaire/settings screens.
2. Compress user form copy and layout into one strict column.
3. Rebuild questionnaire editor into one column with native drag-and-drop ordering.
4. Reduce settings to one short vertical form with only actionable labels and feedback.
5. Run frontend verification and sync planning/docs.

## Verification

- `cd frontend && npm run lint`
- `cd frontend && npm run build`
- `cd frontend && npx tsc --noEmit`

## Notes

- Keep existing validation, success/error feedback, and destructive confirmations where already useful.
