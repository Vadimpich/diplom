# Plan 17-01: Rebuild admin users and questionnaires into compact table-first registries

## Goal

Replace card-heavy admin registries with compact list-first tables that expose only the fields needed to filter, scan, and open a record.

## Scope

- `frontend/app/(app)/admin/users/page.tsx`
- `frontend/app/(app)/admin/questionnaires/page.tsx`
- `frontend/components/admin/user-list.tsx`
- `frontend/components/admin/questionnaire-list.tsx`

## Steps

1. Remove descriptive page copy and keep only title plus create action.
2. Compress users registry to inline filters and a dense clickable table with `login`, `role`, `status`, `last_login`.
3. Compress questionnaires registry to inline filters and a dense clickable table with `name`, `questions_count`, `status`, `updated_at`.
4. Preserve honest loading, empty, filtered-empty, and error states without adding summary chrome.
5. Run frontend verification and sync planning/docs.

## Verification

- `cd frontend && npm run lint`
- `cd frontend && npm run build`
- `cd frontend && npx tsc --noEmit`

## Notes

- No contract changes expected in this phase.
