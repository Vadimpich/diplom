# Plan 18-01: Reduce admin audit and monitoring to plain operational status surfaces

## Goal

Turn audit and monitoring into quiet read-only admin tools based on filters, tables, and expandable details instead of dashboard cards.

## Scope

- `frontend/app/(app)/admin/audit/page.tsx`
- `frontend/components/admin/audit-filter-form.tsx`
- `frontend/components/admin/audit-event-list.tsx`

## Steps

1. Remove descriptive audit page copy and card-wrapped filter chrome.

3. Replace monitoring dashboard cards with a single honest status list using existing data only.
4. Run frontend verification and sync planning/docs.
